# PRO Calculator — Professional Edition

A modern, themeable calculator — single file, no build step.

**Live demo:** Enable GitHub Pages after push (Settings → Pages → Deploy from branch → `main` → `/root`)

## Features
- Clean dark/light/ocean/forest/sunset/rose/nord/amoled themes
- Keyboard support, history, responsive layout

## Usage
Just open `index.html` in any browser. No dependencies.

## Deploy
This repo is ready for GitHub Pages — push `index.html` to `main` branch.
